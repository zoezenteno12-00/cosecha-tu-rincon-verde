# Cosecha Tu Rincon Verde

Este es un sitio web diseñado para que los usuarios comiencen un huerto casero por su cuenta y con los recursos con los que cuentan. El sitio incluye información general sobre opciones de plantas para cultivar, en qué estaciones conviene hacerlo, los materiales que se necesitan, algunos tips y finalmente un formulario para ayudar a los usuarios a armar un plan para comenzar.
